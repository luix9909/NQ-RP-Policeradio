# شبكة الراديو — Police Radio Chat + بلاغات

## المزايا
- 🎙 نداء لاسلكي حي (Push To Talk) بمؤثر صوت راديو حقيقي (بندباس + تشويه + ضوضاء خلفية خفيفة).
- 🔊 صوت زر الضغط والإفلات من ملفين mp3 حقيقيين (مو مركّبين برمجياً).
- 📋 نظام بلاغات: عنصر عائم يمكن سحبه بأي مكان بالشاشة، يعرض البلاغات وحدة وحدة مع أسهم للتنقل (الأقدم / الأحدث)، زر (+) لرفع بلاغ جديد، وزرَي قبول/رفض.
- 🔒 من يقبل بلاغ عادي ما يقدر يقبل غيره إلا بعد ما ينهي بلاغه الحالي (زر إنهاء + تأكيد).
- 🚨 زر بانيك (طوارئ): يكتب المستخدم الموقع فقط، ويظهر فوراً كتنبيه إجباري على شاشات الجميع، وأي شخص يقدر يستجيب له حتى لو عنده بلاغ آخر مفتوح.
- 📶 شريط حالة يعرض من يستجيب الآن ولأي موقع.
- 🔑 الدخول بالبريد الإلكتروني + رمز اعتماد ثابت لا يتغيّر (يُنشأ مرة واحدة فقط عند إنشاء الحساب).
- 📱 تصميم متجاوب يعمل على الجوال والتابلت وسطح المكتب (قائمة جانبية منسدلة على الجوال).

## التشغيل محلياً
```
npm install
npm start
```
عند أول تشغيل، السيرفر يطبع بريد ورمز دخول المالك بالـ console — احفظه فوراً، ما يظهر مرة ثانية.
بريد المالك مضبوط مسبقاً على: **slomsalman2@gmail.com**

## إدارة الحسابات
- المالك فقط (أنت) يقدر يعطي صلاحيات إداري.
- من لوحة الإدارة (⚙) تنشئ حساب جديد بإدخال الاسم + البريد الإلكتروني، والنظام يولّد رمز اعتماد ثابت تلقائياً.
- سلّم الشخص بريده + رمزه، وبهم يدخل. الرمز لا يتغيّر أبداً بعد إنشائه.

## الرفع (Render.com - مجاني)
1. ارفع هذا المجلد إلى GitHub (repo جديد).
2. روح إلى https://render.com وسجل حساب (بدون بطاقة).
3. New + → Web Service → اختر الـ repo.
4. الإعدادات:
   - Build Command: npm install
   - Start Command: npm start
   - Instance Type: Free
5. اضغط Deploy. بعد الانتهاء بيعطيك رابط مثل: https://your-app.onrender.com
6. افتح الرابط، وشوف بريد ورمز المالك من تبويب Logs بالداشبورد (نفس السطر اللي يطبعه السيرفر).

ملاحظة: الخطة المجانية بـ Render "تنام" بعد ٥-١٥ دقيقة خمول، وأول طلب بعدها ياخذ ٣٠-٦٠ ثانية للاستيقاظ.
لو تبي سيرفر ما ينام أبداً ومجاني: جرب Northflank أو Koyeb (يطلبون بطاقة للتحقق فقط، بدون خصم).

## قاعدة البيانات
SQLite (ملف radio.db يتولد تلقائياً بجانب السيرفر) — يحفظ المستخدمين، الرموز، الرسائل، الموجات، والبلاغات.
⚠️ على Render المجاني القرص غير دائم (ephemeral) — أي إعادة نشر (redeploy) تمسح radio.db وترجع كل شي للصفر (بما فيها رمز المالك، سيتولد رمز جديد ويُطبع من جديد بالـ Logs).
للحفظ الدائم مجاناً: أضف "Persistent Disk" (غير متوفر بالمجاني)، أو انقل قاعدة البيانات لخدمة خارجية مجانية مثل Turso أو Supabase لاحقاً.

## الصوت (WebRTC)
يستخدم STUN عام من Google + TURN عام مجاني من Open Relay Project (metered.ca) كحل احتياطي.
هذا TURN عام مشترك بين آلاف المشاريع، فقد يكون بطيء وقت الازدحام. يشتغل ممتاز على شبكات عادية/واي فاي.
لو واجهت مشاكل اتصال صوت من شبكات شركات مقيدة، الحل يكون TURN خاص (يحتاج سيرفر صغير مدفوع لاحقاً).

## ملفات الصوت
- `public/audio/press.mp3` — يشتغل عند الضغط على زر التحدث.
- `public/audio/release.mp3` — يشتغل عند إفلات زر التحدث.
يمكنك استبدال هذين الملفين بأي وقت لاحق بنفس الاسم لتغيير الصوت.
