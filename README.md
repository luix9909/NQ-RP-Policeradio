# شبكة الراديو — Police Radio Chat

## التشغيل محلياً
```
npm install
npm start
```
عند أول تشغيل، السيرفر يطبع رمز دخول المالك بالـ console — احفظه فوراً، ما يظهر مرة ثانية.

## الرفع (Render.com - مجاني)
1. ارفع هذا المجلد إلى GitHub (repo جديد).
2. روح إلى https://render.com وسجل حساب (بدون بطاقة).
3. New + → Web Service → اختر الـ repo.
4. الإعدادات:
   - Build Command: npm install
   - Start Command: npm start
   - Instance Type: Free
5. اضغط Deploy. بعد الانتهاء بيعطيك رابط مثل: https://your-app.onrender.com
6. افتح الرابط، وشوف رمز المالك من تبويب Logs بالداشبورد (نفس السطر اللي يطبعه السيرفر).

ملاحظة: الخطة المجانية بـ Render "تنام" بعد ٥-١٥ دقيقة خمول، وأول طلب بعدها ياخذ ٣٠-٦٠ ثانية للاستيقاظ.
لو تبي سيرفر ما ينام أبداً ومجاني: جرب Northflank أو Koyeb (يطلبون بطاقة للتحقق فقط، بدون خصم).

## قاعدة البيانات
SQLite (ملف radio.db يتولد تلقائياً بجانب السيرفر) — يحفظ المستخدمين، الرموز، الرسائل، الموجات.
⚠️ على Render المجاني القرص غير دائم (ephemeral) — أي إعادة نشر (redeploy) تمسح radio.db وترجع الرموز/الرسائل للصفر.
للحفظ الدائم مجاناً: أضف "Persistent Disk" (غير متوفر بالمجاني)، أو انقل قاعدة البيانات لخدمة خارجية مجانية مثل Turso أو Supabase لاحقاً.

## الصوت (WebRTC)
يستخدم STUN عام من Google + TURN عام مجاني من Open Relay Project (metered.ca) كحل احتياطي.
هذا TURN عام مشترك بين آلاف المشاريع، فقد يكون بطيء وقت الازدحام. يشتغل ممتاز على شبكات عادية/واي فاي.
لو واجهت مشاكل اتصال صوت من شبكات شركات مقيدة، الحل يكون TURN خاص (يحتاج سيرفر صغير مدفوع لاحقاً).
